## 🚀 ¿Qué es Corios CMMS?
Corios CMMS es un sistema profesional para la gestión computarizada del mantenimiento. Está diseñado específicamente para ayudar a los departamentos de mantenimiento a registrar, organizar y hacer seguimiento a todas sus operaciones.

### Funcionalidades principales:
* **Gestión de Órdenes de Trabajo (OTs):** Creación, asignación, seguimiento y cierre de reportes de fallas.
* **Inventario y Almacén:** Control estricto de las refacciones, alertas de stock crítico y reorden.
* **Gestión de Maquinaria:** Catálogo completo de equipos y sistemas.
* **Indicadores KPI:** Cálculo automático de Disponibilidad, **MTTR** (Tiempo Medio Para Reparar) y **MTBF** (Tiempo Medio Entre Fallas).
* **Seguridad y Licenciamiento:** Sistema robusto de validación por hardware (Hardware UUID) sincronizado en la nube para asegurar cada instalación.

## 📥 Descargas e Instalación

Para instalar el programa, dirígete a la sección de **[Releases](https://github.com/CoriosMwRaw/Corios_CMMS-Releases/releases)** de este repositorio y descarga el archivo `.exe` de la versión más reciente.

> **Nota:** El instalador ya contiene el entorno de ejecución y las librerías necesarias empaquetadas, por lo que no es necesario instalar dependencias de terceros para ejecutarlo.
